# Discover - Portfolio Project

Este projeto é uma aplicação web desenvolvida durante o curso **Discover da Rocketseat**, focada em consolidar os fundamentos de desenvolvimento web e programação.

---

### 🛠️ Tecnologias Utilizadas

- **Python:** Lógica e backend
- **HTML5:** Estruturação da página
- **CSS3:** Estilização e layout

---

### 📌 Sobre o Projeto

O objetivo principal deste repositório é aplicar na prática os conceitos aprendidos ao longo do curso, construindo um portfólio funcional e desenvolvendo uma base sólida em código.
